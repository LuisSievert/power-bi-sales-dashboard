# 📊 NEXUS — Business Intelligence

Dashboard corporativo desenvolvido em Power BI para análise estratégica
de vendas, estoque, logística e desempenho financeiro.

## 🎯 Objetivo

Desenvolver uma solução de Business Intelligence capaz de transformar
dados operacionais e comerciais em indicadores e análises visuais para
apoio à tomada de decisão.

O projeto foi estruturado com diferentes áreas de análise, permitindo
uma visão executiva e também uma análise mais detalhada dos dados.

## ⚠️ Sobre os dados

Este projeto utiliza dados fictícios desenvolvidos exclusivamente para
fins de estudo, demonstração técnica e composição de portfólio.

Nenhum dado representa uma empresa, cliente ou operação real.

## 📌 Áreas do Dashboard

### Visão Executiva

Apresenta os principais indicadores de desempenho da operação:

- Faturamento
- Lucro
- Margem de lucro
- Evolução mensal
- Desempenho semanal
- Indicadores operacionais

### Gestão Logística

Permite analisar:

- Volume transportado
- Total de viagens
- Desempenho por veículo
- Tempo de operação
- Peso transportado
- Capacidade utilizada
- Capacidade livre

### Análise de Materiais

Apresenta análises relacionadas à classificação e desempenho dos
materiais:

- Curva ABC Financeira
- Distribuição do faturamento por classe
- Faturamento por classe
- Análise de Pareto
- Ranking de materiais
- Participação percentual no faturamento

### Receita, Vendas e Financeiro

Apresenta indicadores financeiros e comerciais:

- Faturamento
- Volume de vendas
- Lucro
- Margem de lucro
- Lucro por produto
- Lucro unitário
- Receita por material
- Evolução da margem

## 🛠️ Tecnologias e Recursos

- Power BI
- DAX
- Power Query
- CSV
- HTML/CSS
- Modelagem de Dados
- Visualização de Dados
- KPIs
- Narrativa Inteligente

## 🔎 Interatividade

O dashboard possui elementos interativos que permitem ao usuário
explorar os indicadores e obter informações adicionais durante a
navegação.

Alguns KPIs e elementos visuais utilizam tooltips para apresentar
informações complementares ao passar o cursor sobre os elementos.

Também foram utilizados recursos de interação entre páginas,
filtros e navegação para facilitar a exploração dos dados.

## 🧠 Narrativa Inteligente

O projeto utiliza o recurso de Narrativa Inteligente do Power BI para
apresentar informações complementares sobre os principais indicadores
e auxiliar na interpretação dos dados.

## 🎨 Interface

A interface foi desenvolvida buscando uma experiência de navegação
semelhante a um painel corporativo de Business Intelligence, com
separação das análises por áreas de negócio.

Elementos em HTML/CSS foram utilizados para personalização da interface
e apresentação dos componentes visuais.
